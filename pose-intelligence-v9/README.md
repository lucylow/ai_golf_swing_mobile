# Pose Intelligence V9 — Technical AI/Data Upgrade

This is the next layer on top of the existing V5/V8 golf intelligence work.

## Technical focus

- MediaPipe Pose Landmarker-compatible 33 landmark contract.
- Live-stream/video/image runtime semantics.
- Confidence-aware native result mapping.
- Adaptive smoothing and bounded gap repair.
- Canonical body coordinates.
- Temporal resampling and event/phase detection.
- Golf-specific kinematics and club-path proxies.
- Embeddings, prototype retrieval, robust statistics, and ensemble fusion.
- Data schemas, feature store, deterministic splits, leakage checks, augmentation.
- Evaluation, drift, performance budgets, model registry, runtime policy, quantization policy.
- Privacy-safe telemetry and model health.
- Native Swift/Python reference boundaries.

The algorithms in this layer are engineering implementations/proxies. Production accuracy claims require real annotated swing datasets and independent validation.
