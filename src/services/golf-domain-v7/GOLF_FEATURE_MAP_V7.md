# V7 Feature Map

1. Swing intelligence: shot shape, face/path matrix, tempo, sequence, swing plane, center-of-mass proxy, delivery window, impact window.
2. Ball flight: launch, spin, speed, strike, lie, wind, elevation and curvature-aware estimates.
3. Equipment: club catalog, gapping, overlap, set makeup, club recommendation.
4. On-course strategy: hazard model, target windows, wind strategy, pin strategy, layup strategy.
5. Short game: chip windows, pitch windows, bunker entry.
6. Putting: start line, distance control, break model.
7. Scoring: expected score, decision score, approach quality, tee-shot risk, round summary.
8. Practice: weakness prioritization, drill generation, session planning, progression and deterministic randomization.
9. A.I. layer: context builder, insight ranking, confidence, explanation, recommendations, guardrails.
10. Integration: V7 bridge + existing app bridge.
